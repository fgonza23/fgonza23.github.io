# fgonza23.github.io

Personal site for Francisco Gonzalez, served by GitHub Pages at https://fgonza23.github.io/.

Plain static HTML/CSS/JS, no build step. Push to `master` to deploy.

- `index.html` – the page
- `css/style.css`, `css/responsive.css` – styles (mobile rules in `responsive.css`)
- `js/main.js` – navbar, smooth scroll, header typing animation, skills carousel
- `js/contact.js` – contact form, sent through [FormSubmit](https://formsubmit.co) because GitHub Pages can't run server code
- `lib/` – vendored jQuery 3, Bootstrap 4 CSS, Ionicons 2, Owl Carousel 2, Typed.js
